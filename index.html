NBA stat predictor

Pick a player and a matchup to see their projected stat line for the next game, then set any line to get over/under odds. Projections come from a gradient-boosted model tested on games it never saw.

    How accurate is it?

    Trained on 2015–2023, calibrated on 2023–24, and scored on games from 2024–25 the model never saw. Each prediction uses only what was known before tip-off.
